ADDRESS RESOLUTION PROTOCOL

explained.

ARP:
The Address Resolution Protocol (ARP) is a communication protocol for discovering the link layer address, such as a MAC address, associated with an internet layer address, typically an IPv4 address.

Functionality:
ARP enables a host to send an IPv4 packet to another node in the local network by providing a protocol to get the MAC address associated with an IP address.

Implementation:
ARP has been implemented with many combinations of network and data link layer technologies, such as IPv4, Chaosnet, DECnet, and Xerox PARC Universal Packet (PUP) using IEEE 802 standards, FDDI, X.25, Frame Relay, and Asynchronous Transfer Mode (ATM).

IPv6:
In Internet Protocol Version 6 (IPv6) networks, the functionality of ARP is provided by the Neighbor Discovery Protocol (NDP).

Message Format:
ARP uses a simple message format containing one address resolution request or response.
The packets are carried at the data link layer of the underlying network as raw payload.

ARP Cache:
ARP Cache is a temporary storage table maintained by a device.
It stores recently resolved IP-to-MAC address mappings.

ARP Request:
ARP Request is a broadcast message sent to all devices in the local network.
It asks, “Who has this IP address?”

ARP Reply:
ARP Reply (ARP Response) is a unicast message sent by the device that owns the requested IP address. It contains the corresponding MAC address.

Types of ARP:
There are four main types of ARP, each used in different scenarios: Proxy ARP, Gratuitous ARP, and others.

Dynamic Mapping:
ARP provides a dynamic mapping from an IP address to the corresponding hardware address.
